# Roman Ten

Applied AI and full-stack engineer based in Suwon, South Korea. I build software across data ingestion, retrieval, backend APIs, and user-facing interfaces.

## Featured work

**[WRS](https://wrs.kz)** is a website knowledge assistant with a FastAPI backend, PostgreSQL/pgvector hybrid retrieval, source-linked answers, and an embeddable JavaScript widget. I built its ingestion and retrieval pipeline, application API, widget, and deployment workflows. [Explore the implementation](https://github.com/xenostate/ragskill).

**[Local LLM fine-tuning for flashcards](https://github.com/xenostate/qwen-flashcard-qlora)** adapts a 4-bit Qwen3-VL-8B model to produce structured JSON flashcards from educational passages. The repository documents the training data, validation, and a small preliminary evaluation. [Read the model card](https://huggingface.co/tenroman/qwen3-vl-8b-flashcard-qlora).
